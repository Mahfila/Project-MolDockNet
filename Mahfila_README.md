## 📌 Featured Projects

### 🧪 [MolDockNet](https://github.com/Mahfila/MolDockNet) — Hybrid Deep Learning for Virtual Drug Screening

> GNN + Morgan Fingerprint fusion model for predicting molecular docking scores from SMILES strings. Applied at scale to ~3.5M compounds against the 5-HT1B target.

**Architecture:** Dual-stream encoder — GINEConv graph network (local chemical environment) fused with residual fingerprint MLP (global substructure patterns).

`PyTorch` `PyTorch Geometric` `RDKit` `GNN` `Cheminformatics`

- R² **0.81** · RMSE **1.23 kcal/mol** · Enrichment Factor **8.4×** at top 1%
- Full training pipeline with early stopping, cosine LR scheduling, and virtual screening evaluation
- [📓 Interactive Notebook Demo](https://github.com/Mahfila/MolDockNet/blob/main/notebooks/01_MolDockNet_Demo.ipynb)
